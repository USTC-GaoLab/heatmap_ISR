# Heatmap_ISR

## Overview

This repository contains heatmap visualization resources for interferon-stimulated response related analysis.

## Repository structure

- `R/GY-HH` - preserved ISR differential-expression and heatmap workflow
- `examples/` - location for small, non-sensitive examples
- `docs/` - tool review and structure documentation

The workflow currently contains source-machine paths. Configure those paths for
the execution environment before running it; do not commit the referenced raw data.

## Usage

Please provide input matrix format, gene list source, and plotting parameters when updating this repository.

## Reproducibility

Record analysis environment and software versions in `ENVIRONMENT.md`.
